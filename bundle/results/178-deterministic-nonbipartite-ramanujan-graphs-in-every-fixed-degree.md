# 178. Deterministic nonbipartite Ramanujan graphs in every fixed degree

> Discipline: [Combinatorics](../disciplines/combinatorics.md)
> Manuscripts: **1**

## Description

For every fixed <i>d</i> ≥ 3, constructs a simple <i>d</i>-regular nonbipartite Ramanujan graph on every sufficiently large even number <i>n</i> of vertices, with every nonconstant adjacency eigenvalue strictly between $`-2\sqrt{d-1}`$ and $`2\sqrt{d-1}`$. A deterministic algorithm outputs the full adjacency list in polynomial bit time, with exponent depending on <i>d</i>.
