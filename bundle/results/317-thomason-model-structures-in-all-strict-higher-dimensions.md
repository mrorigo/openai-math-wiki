# 317. Thomason model structures in all strict higher dimensions

> Discipline: [Topology](../disciplines/topology.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/317.md)

## Description

Resolves the Ara–Maltsiniotis conjecture: for every <i>n</i> ≥ 1 and <i>n</i> = <i>ω</i>, small strict globular <i>n</i>-categories admit proper combinatorial Thomason model structures Quillen equivalent to simplicial sets. Thus strict higher categories model the homotopy theory of spaces in every stated dimension.
