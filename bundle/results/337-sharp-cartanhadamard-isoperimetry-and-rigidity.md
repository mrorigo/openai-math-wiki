# 337. Sharp Cartan–Hadamard isoperimetry and rigidity

> Discipline: [Differential geometry](../disciplines/differential-geometry.md)
> Manuscripts: **2**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/337.md)

## Description

Proves generalized Cartan–Hadamard isoperimetry in every dimension: in a complete simply connected manifold with sectional curvature at most <i>κ</i> ≤ 0, every finite-volume finite-perimeter set satisfies the sharp comparison with the equal-volume model ball. Bounded positive-volume equality regions for <i>κ</i> = 0 are Euclidean balls. Also proves sharp Euclidean filling bounds for compactly supported integral <i>n</i>-cycles, <i>n</i> ≥ 2, in arbitrary proper CAT$`(0)`$ spaces.
