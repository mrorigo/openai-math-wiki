# 132. A superquadratic separation of sensitivity and block sensitivity

> Discipline: [Theoretical computer science](../disciplines/theoretical-computer-science.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/132.md)

## Description

Constructs total Boolean functions with block sensitivity $`\mathop{\mathrm{bs}}\nolimits (f)\ge s(f)^\alpha`$ for a fixed <i>α</i> &gt; 2, disproving the quadratic strengthening of the Sensitivity Conjecture. Here $`s(f)`$ counts influential individual-bit flips, while block sensitivity allows disjoint groups of bits to change together.
