# 029. Primitive roots for every admissible integer base

> Discipline: [Number theory](../disciplines/number-theory.md)
> Manuscripts: **2**

## Description

Proves the infinitude assertion in Artin's primitive root conjecture for every integer <i>a</i> that is neither −1 nor a square. For each such base, at least $`c_a x/(\log x)^2`$ primes in every sufficiently large interval $`(x,2x)`$ have primitive root <i>a</i>, with $`c_a\gt 0`$.
