# 192. Boolean functions violate the square-root degree bound by arbitrary factors

> Discipline: [Combinatorics](../disciplines/combinatorics.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/192.md)

## Description

Disproves the proposed square-root bound relating a Boolean function's linear Fourier coefficients to its polynomial degree. For every <i>C</i> &gt; 0, there is a sign-valued Boolean function <i>f</i> with $`\sum_i\widehat f(\{i\})\gt C\sqrt{\deg(f)}`$. Thus its total signed correlation with individual input bits can exceed the proposed bound by an arbitrary factor.
