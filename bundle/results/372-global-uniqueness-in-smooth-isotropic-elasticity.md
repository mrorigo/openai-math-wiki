# 372. Global uniqueness in smooth isotropic elasticity

> Discipline: [Partial differential equations](../disciplines/partial-differential-equations.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/372.md)

## Description

Proves that full static boundary displacement-to-traction data determine both smooth real Lamé moduli on every bounded connected smooth domain in ℝ<sup>3</sup>, provided <i>μ</i> &gt; 0 and $`3\lambda+2\mu\gt 0`$ on the closure. Neither analyticity, proximity to constant coefficients nor prior knowledge near the boundary is required.
