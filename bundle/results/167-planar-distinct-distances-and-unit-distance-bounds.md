# 167. Planar distinct distances and unit-distance bounds

> Discipline: [Combinatorics](../disciplines/combinatorics.md)
> Manuscripts: **2**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/167.md)

## Description

Proves the weak pinned Erdős distance conjecture: for every fixed <i>ε</i> &gt; 0, all but $`o(n)`$ points of any <i>n</i>-point planar set determine at least $`n^{1-\varepsilon}`$ distinct nonzero distances. A complementary theorem bounds the number of unit-distance pairs by $`O(n^{4/3-\delta})`$ for an absolute <i>δ</i> &gt; 0.
