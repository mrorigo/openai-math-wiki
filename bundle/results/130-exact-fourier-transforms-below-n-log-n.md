# 130. Exact Fourier transforms below $`n\log n`$

> Discipline: [Theoretical computer science](../disciplines/theoretical-computer-science.md)
> Manuscripts: **2**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/130.md)

## Description

Gives a deterministic length-<i>n</i> discrete Fourier transform algorithm using $`O(n(\log n)^{1-\delta})`$ operations for every <i>n</i>, with explicit $`\delta=10^{-13}`$. The model uses exact complex arithmetic, unrestricted coefficients and a supplied root of unity, and counts scalar preparation and logarithmic-word indexing.
