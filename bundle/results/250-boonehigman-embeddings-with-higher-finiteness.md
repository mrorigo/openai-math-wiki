# 250. Boone–Higman embeddings with higher finiteness

> Discipline: [Group theory](../disciplines/group-theory.md)
> Manuscripts: **3**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/250.md)

## Description

A finitely generated group has decidable word problem exactly when it embeds in a finitely presented simple group, proving the Boone–Higman conjecture. The target can have type <i>F</i><sub>∞</sub>: a classifying space with finitely many cells in each dimension. A single group of type <i>F</i><sub>∞</sub> can also contain every finitely presented group.
