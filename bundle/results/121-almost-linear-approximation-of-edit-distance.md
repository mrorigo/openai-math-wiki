# 121. Almost-linear approximation of edit distance

> Discipline: [Theoretical computer science](../disciplines/theoretical-computer-science.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/121.md)

## Description

For every fixed rational $`\varepsilon\in(0,1)`$, gives a randomized $`(1+\varepsilon)`$ approximation to unit-cost edit distance in worst-case expected time $`N^{1+o(1)}`$, with success probability at least 2/3. The strings have total length <i>N</i> and polynomially bounded integer symbols. This is an asymptotic guarantee at fixed accuracy.
