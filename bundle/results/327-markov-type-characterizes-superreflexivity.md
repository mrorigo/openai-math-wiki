# 327. Markov type characterizes superreflexivity

> Discipline: [Functional analysis](../disciplines/functional-analysis.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/327.md)

## Description

Proves that every real Banach space with Markov type <i>p</i> for some <i>p</i> &gt; 1 admits an equivalent uniformly convex norm, answering Naor's renorming question. Together with the known converse, this characterizes superreflexivity by nontrivial Markov type.
