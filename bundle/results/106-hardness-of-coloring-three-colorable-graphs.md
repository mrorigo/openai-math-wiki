# 106. Hardness of coloring three-colorable graphs

> Discipline: [Theoretical computer science](../disciplines/theoretical-computer-science.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/106.md)

## Description

It is NP-hard to color a three-colorable graph using any fixed number <i>c</i> ≥ 3 of colors. More strongly, for every fixed $`0\lt \delta\lt 1/3`$, a deterministic polynomial-time reduction from 3SAT produces simple unweighted graphs that are three-colorable in the satisfiable case and have no independent set of size $`\delta n`$ otherwise, where <i>n</i> is the number of vertices.
