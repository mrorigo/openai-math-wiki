# 245. Weak normalization implies strong normalization in pure type systems

> Discipline: [Mathematical logic](../disciplines/mathematical-logic.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/245.md)

## Description

Proves that weak normalization implies strong normalization for every pure type system: if every legal expression in every valid context has a <i>β</i>-normal form, every <i>β</i>-reduction sequence terminates. This resolves the <i>β</i>-Barendregt–Geuvers–Klop conjecture, including nonfunctional rules and open contexts.
