# 110. Optimal-order randomized <i>k</i>-server on arbitrary metrics

> Discipline: [Theoretical computer science](../disciplines/theoretical-computer-science.md)
> Manuscripts: **2**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/110.md)

## Description

Establishes a randomized competitive ratio $`O(\log^2(k+1))`$ for <i>k</i>-server on every metric space, matching the worst-case lower-bound order. One policy serves every finite oblivious request sequence, including on infinite unbounded metrics. On finite rational metrics, a uniform implementation has polynomial preprocessing and per-request bit cost in the input length and $`\log(t+1)`$ at request <i>t</i>, with a finite instance-dependent additive movement constant.
