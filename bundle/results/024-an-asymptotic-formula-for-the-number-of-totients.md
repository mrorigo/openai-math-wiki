# 024. An asymptotic formula for the number of totients

> Discipline: [Number theory](../disciplines/number-theory.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/024.md)

## Description

Gives an asymptotic equivalent for the number $`V(x)`$ of distinct totient values up to <i>x</i>, with a positive bounded phase-dependent factor determined by convergent arithmetic approximations. In particular, $`V(cx)/V(x)\to c`$ for every fixed <i>c</i> &gt; 0, answering Erdős and Hall’s scaling question.
