# 371. Stable blowup for the defocusing Schrödinger equation

> Discipline: [Partial differential equations](../disciplines/partial-differential-equations.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/371.md)

## Description

For a sufficiently large odd nonlinearity power, constructs a nonempty open set of initial data in $`H^k(\mathbb T^{12})`$, with <i>k</i> &gt; 8, whose solutions of the scalar defocusing nonlinear Schrödinger equation blow up in finite time. Thus finite-time blowup is stable under Sobolev perturbations in this supercritical regime.
