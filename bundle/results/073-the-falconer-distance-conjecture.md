# 073. The Falconer distance conjecture

> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/073.md)

## Description

Resolves the Falconer distance conjecture in every dimension <i>d</i> ≥ 2: every compact set $`E\subset\mathbb R^d`$ with Hausdorff dimension greater than $`d/2`$ determines a set of Euclidean distances of positive Lebesgue measure.
