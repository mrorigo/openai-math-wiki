# 184. Correspondence coloring with a fixed forbidden subgraph

> Discipline: [Combinatorics](../disciplines/combinatorics.md)
> Manuscripts: **2**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/184.md)

## Description

Proves the Alon–Krivelevich–Sudakov coloring conjecture in correspondence-coloring form: graphs avoiding any fixed subgraph <i>F</i> need $`O_F(\Delta/\log\Delta)`$ colors when their maximum degree Δ is sufficiently large. Also proves the Ajtai–Erdős–Komlós–Szemerédi independence conjecture: for fixed <i>r</i> ≥ 4, every <i>n</i>-vertex <i>K</i><sub><i>r</i></sub>-free graph of average degree <i>d</i> ≥ 2 has an independent set of size $`\Omega_r(n\log d/d)`$.
