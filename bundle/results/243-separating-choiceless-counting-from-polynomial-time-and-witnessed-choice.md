# 243. Separating choiceless counting from polynomial time and witnessed choice

> Discipline: [Mathematical logic](../disciplines/mathematical-logic.md)
> Manuscripts: **2**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/243.md)

## Description

Confirms the Blass–Gurevich–Shelah noncapture conjecture: consistency of a linear system over 𝔽<sub>3</sub> defines a polynomial-time query on unordered finite structures that choiceless polynomial time with counting cannot express. A separate result shows that adding witnessed symmetric choice strictly increases expressive power. Both separations hold for the full counting formalism, allowing hereditarily finite sets of arbitrary finite rank.
