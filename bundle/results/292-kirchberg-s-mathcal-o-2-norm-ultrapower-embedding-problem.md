# 292. Kirchberg's $`\mathcal O_2`$ norm-ultrapower embedding problem

> Discipline: [Operator algebras](../disciplines/operator-algebras.md)
> Manuscripts: **1**

[Lean formalization of headline result](https://github.com/openai/math/blob/main/lean/docs/292.md)

## Description

Constructs an explicit separable unital full group <i>C</i><sup>∗</sup>-algebra that cannot embed unitally into the norm ultrapower of any fixed nonzero unital nuclear <i>C</i><sup>∗</sup>-algebra, for any free ultrafilter on the natural numbers. Taking the target to be $`\mathcal O_2`$ answers Kirchberg's norm-ultrapower embedding problem negatively.
