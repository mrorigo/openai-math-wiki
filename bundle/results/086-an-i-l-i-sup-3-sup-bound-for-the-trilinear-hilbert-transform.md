# 086. An <i>L</i><sup>3</sup> bound for the trilinear Hilbert transform

> Discipline: [Real and complex analysis](../disciplines/real-and-complex-analysis.md)
> Manuscripts: **1**

## Description

Proves that the principal-value trilinear Hilbert transform with shifts $`x-t`$, $`x-2t`$, $`x-3t`$ is bounded from $`L^3(\mathbb R)^3`$ to $`L^1(\mathbb R)`$. This resolves the <i>L</i><sup>3</sup> exponent case of the standard conjecture for slopes 1, 2, 3.
