# 368. The three-dimensional Ball–Evans approximation problem

> Discipline: [Partial differential equations](../disciplines/partial-differential-equations.md)
> Manuscripts: **2**

## Description

Resolves the three-dimensional Ball–Evans approximation problem: every $`W^{1,p}`$ homeomorphism between arbitrary bounded domains in ℝ<sup>3</sup>, for $`1\le p\lt \infty`$, is a strong $`W^{1,p}`$ limit of smooth diffeomorphisms onto the same target.
