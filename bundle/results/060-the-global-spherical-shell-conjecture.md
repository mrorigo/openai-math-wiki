# 060. The Global Spherical Shell conjecture

> Discipline: [Algebraic and complex geometry](../disciplines/algebraic-and-complex-geometry.md)
> Manuscripts: **1**

## Description

Every connected minimal compact complex surface of class VII with $`b_2\gt 0`$ contains a global spherical shell, proving the positive-<i>b</i><sub>2</sub> Global Spherical Shell conjecture. Such a shell is a holomorphically embedded neighborhood of the standard three-sphere in $`\mathbb C^2\setminus\{0\}`$ whose complement is connected.
