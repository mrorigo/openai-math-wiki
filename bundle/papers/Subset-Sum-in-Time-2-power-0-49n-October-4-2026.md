## Abstract

We give a uniform randomized classical algorithm for Subset Sum with bounded error and worst-case running time $`O(2^{0.49n})`$ on polynomial-bit inputs in a word-RAM model, where <i>n</i> is the number of input integers. The time bound holds on every random execution.
