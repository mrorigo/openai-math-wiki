## Abstract

We disprove the Auslander–Reiten conjecture for Artin algebras. We construct a finite-dimensional algebra Λ over $`k=\mathbb F_2(q,H_1,H_2)`$ and a finite-dimensional nonprojective left module <i>Z</i> such that $`\mathop{\mathrm{Ext}}\nolimits ^i_\Lambda(Z,Z)=\mathop{\mathrm{Ext}}\nolimits ^i_\Lambda(Z,\Lambda)=0`$ for every <i>i</i> &gt; 0. The module is Gorenstein-projective, so the same example also disproves the Gorenstein-projective conjecture. Both counterexamples persist after every extension of <i>k</i>.
